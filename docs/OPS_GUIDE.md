# HAN OPS 가이드 레퍼런스

> 딜러팀 스케줄·신청·운영 웹앱 사용 요약  
> 사이트: https://geniusking0214.github.io/Han_OPS/

---

## 1. 빠른 시작

```
로그인 → 가입 승인 대기 → Settings(프로필·푸시) → Schedule에서 슬롯 신청
```

| # | 할 일 | 위치 |
|---|--------|------|
| 1 | Google 로그인 | `/login` |
| 2 | 관리자 승인 대기 | 승인 전 앱 이용 불가 |
| 3 | 푸시 알림 켜기 | `/settings` |
| 4 | 일정 신청 | `/schedule` |

**iPhone** — Safari → 공유 → **홈 화면에 추가** → 아이콘으로 실행 (푸시 필수)

## 2. 메뉴 맵

### 멤버

| 메뉴 | 경로 | 한 줄 설명 |
|------|------|------------|
| Dashboard | `/dashboard` | 오늘 일정·신청 요약 |
| Schedule | `/schedule` | 날짜 선택 → 슬롯 신청 |
| Applications | `/applications` | 내 신청 목록·취소 |
| 취합표 | `/monthly-sheet` | 팀 월간 배치 (읽기 전용) |
| Notices | `/notices` | 공지 확인 |
| Settings | `/settings` | 프로필·푸시 설정 |

### 관리자 (Admin)

| 메뉴 | 경로 | 한 줄 설명 |
|------|------|------------|
| 가입 승인 | `/admin/registrations` | 신규 계정 승인·팀 배정 |
| 사용자 관리 | `/admin/users` | 권한·팀·계정 상태 |
| 일정 | `/admin/schedule` | 스케줄 생성·수정·삭제 |
| 신청 | `/admin/applications` | 대기 신청 승인/거절 |
| 신청 인원 관리 | `/admin/roster` | 당일 명단·근무 상태 |
| 포인트/랭킹 | `/admin/points` | 포인트·랭킹·CSV |
| 월간 취합표 | `/admin/monthly-sheet` | 편집·보내기 |

## 4. 멤버 워크플로

```
① Google 로그인
      ↓
② 관리자 가입 승인 (팀 배정)
      ↓
③ Schedule → 날짜·슬롯 선택 → 신청
      ↓
④ Applications에서 대기/승인/거절 확인
      ↓
⑤ 근무 후 관리자가 근무완료 처리 → 포인트 반영
```

### 신청 취소 규칙

| 상태 | 취소 |
|------|------|
| **대기 중** | ✓ 언제든 |
| **승인 완료** | ✓ 오늘 이후 일정만 |
| **완료됨** | ✗ 불가 |

> 당일 취소는 **−5P** 차감 대상일 수 있음

---

## 5. 관리자 워크플로

```
① 가입 승인 — 팀 배정 후 승인
      ↓
② Admin 일정 — 이벤트·세션·슬롯(정원) 생성
      ↓
③ Admin 신청 — 승인 / 거절 (거절 시 사유)
      ↓
④ 신청 인원 관리 — 당일 명단·근무 상태 기록
      ↓
⑤ 포인트/랭킹 — 랭킹 확인·수동 조정·CSV
```

## 6. 알림

### 멤버가 받는 알림

| 이벤트 | 발생 시점 |
|--------|-----------|
| 새 스케줄 | 관리자 일정 생성 |
| 일정 취소 | 관리자 일정 삭제 |
| 승인 / 거절 | 내 신청 처리 결과 |
| 공지 | 새 공지 (중요 → 대시보드 팝업) |

### 관리자가 받는 알림

| 이벤트 | 발생 시점 |
|--------|-----------|
| 신규 신청 | 멤버 슬롯 신청 |
| 신청 취소 | 멤버가 대기/승인 건 취소 |

알림 경로: 앱 내 **벨 아이콘** + (설정 시) **푸시**

---

## 7. 포인트 정책

| 근무 상태 | 포인트 | 반영 위치 |
|-----------|--------|-----------|
| 근무완료 | **+10P** | Admin → 신청 인원 관리 |
| 결근 | **−10P** | Admin → 신청 인원 관리 |
| 당일취소 | **−5P** | Admin → 신청 인원 관리 |

수동 조정: **Admin → 포인트/랭킹**

## 8. 자주 묻는 상황

| 증상 | 확인 |
|------|------|
| 로그인 후 화면 안 열림 | 가입 승인 대기 — 관리자 문의 |
| 푸시 안 옴 | Settings 알림 허용 · iPhone PWA 설치 후 재실행 |
| 404 | URL에 `/Han_OPS/` 포함 여부 |
| VAPID 오류 | Settings에서 푸시 재등록 |
